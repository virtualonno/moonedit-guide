moonedit · Operator manual

0.1.0-alpha.6 · NeoForge 1.21.1

Type sentences after /mo: the sentence says what and where, flags say how. Tab completes every word; ; chains sentences, each starting once the one before has finished. Edits run as background jobs in the order you send them, and every edit can be undone, even after a restart. Operators need level 2; the console types without the slash and gives coordinates instead of target. The same reference as plain text: the operator guide.
